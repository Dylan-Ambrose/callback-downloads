# Callback, Downloads

This repo hosts downloadable builds of Callback, a job-application tracker, plus the `manifest.json` Guidance reads to offer it as a Download card.

**No source code lives here**, this repo exists solely to distribute release binaries and the manifest. Callback's source is developed privately.

## Get Callback

See the [Releases](../../releases) page for the latest `Callback-Setup.exe`, or add it from within Guidance's own Downloads tab (Guidance 2.36.0+ discovers this repo automatically, see `guidance-downloads/README.md`).

It installs per-user into Guidance's own managed Apps folder by default (`%LOCALAPPDATA%\Programs\Guidance\Apps\Callback`), no admin rights needed, no UAC prompt.

## manifest.json

Read by Guidance to build its app catalogue, schema documented in `guidance-downloads/README.md`.
